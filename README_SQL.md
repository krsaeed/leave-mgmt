## How SQL Works Here (Without Writing SQL)

This project uses **Spring Data JPA + Hibernate** as an ORM (Object Relational Mapper).
You write Java classes, JPA automatically generates and runs the SQL.

### Java Class → Database Table

You write this Java:
```java
@Entity
@Table(name = "employees")
public class Employee {
    private String name;
    private String email;
    private int annualLeaveBalance = 20;
}
```

JPA automatically creates this table in PostgreSQL:
```sql
CREATE TABLE employees (
    id       BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name     VARCHAR(255) NOT NULL,
    email    VARCHAR(255) UNIQUE,
    role     VARCHAR(255) CHECK (role IN ('EMPLOYEE', 'MANAGER')),
    annual_leave_balance INTEGER NOT NULL
);
```

You never wrote that SQL — JPA generated it on startup.

---

### Repository Methods → SQL Queries

You write this Java:
```java
employeeRepository.findAll();
employeeRepository.findById(2L);
employeeRepository.save(employee);
leaveRepository.findByStatus(LeaveStatus.PENDING);
leaveRepository.findByEmployeeId(2L);
```

JPA automatically runs:
```sql
SELECT * FROM employees;
SELECT * FROM employees WHERE id = 2;
INSERT INTO employees (name, email, role, annual_leave_balance) VALUES (?, ?, ?, ?);
SELECT * FROM leave_requests WHERE status = 'PENDING';
SELECT * FROM leave_requests WHERE employee_id = 2;
```

You never wrote any of these queries — JPA generated them from method names!

---

### Table Relationships

`LeaveRequest` has a foreign key to `Employee`:

```java
@ManyToOne
@JoinColumn(name = "employee_id")
private Employee employee;
```

JPA creates this in PostgreSQL:
```sql
ALTER TABLE leave_requests
    ADD CONSTRAINT fk_employee
    FOREIGN KEY (employee_id) REFERENCES employees(id);
```

This means every leave request is linked to an employee in the DB.

---

### How to See the SQL Live

In `application.properties`:
```properties
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
```

This prints every SQL query JPA runs in the terminal — useful for learning and debugging!
```

This makes it clear for anyone reading the repo exactly how JPA bridges Java and PostgreSQL.
